# Academic website GitHub Pages mirror

This folder is a **content-preserving reconstruction** of the published ChatGPT Sites website using its November 23, 2026 saved text projection. It is not the original exported source code.

Original site: https://jameela-computational-materials.fatheema.chatgpt.site/

The original stylesheet, image assets, and interactive teaching widget were not available from the text projection. Local CSS, an illustrative layered-materials graphic, and a static divider figure replace them. To obtain an exact design, ask Codex in the original ChatGPT Site editing session to export its source code, then migrate that source here.

## Publish

Open https://github.com/j-shah-7/j-shah-7/settings/pages and configure **Deploy from a branch** → `main` → `/docs` → **Save**. GitHub Pages should then serve this content at https://j-shah-7.github.io/j-shah-7/ (subject to Pages configuration and deployment).

The existing GitHub profile README.md is untouched.

Do not change poster QR codes until the new URL has been opened and tested on a phone.
